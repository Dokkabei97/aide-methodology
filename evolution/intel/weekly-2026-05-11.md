## Vendor releases (curator-collected, machine sources blocked this run)

### Anthropic — Code w/ Claude 2026 conference (May 6) and follow-ups
- **Multiagent Orchestration → public beta** ([Augment Code summary](https://www.augmentcode.com/tools/multi-agent-orchestration-platforms-build-vs-buy), [9to5Mac](https://9to5mac.com/2026/05/07/anthropic-updates-claude-managed-agents-with-three-new-features/)) — a lead agent decomposes a job into pieces and delegates to up to **20 specialist subagents in parallel** with their own model / prompt / tool set. Specialists share a filesystem and contribute to the lead agent's overall context; the lead can re-check specialists mid-workflow because events are persistent.
- **Outcomes → public beta** ([Rick's Cafe AI analysis](https://cafeai.home.blog/2026/05/10/anthropic-shipped-outcomes-and-real-story-is-verification-becoming-a-sku/), [9to5Mac](https://9to5mac.com/2026/05/07/anthropic-updates-claude-managed-agents-with-three-new-features/)) — developer writes a rubric; a **separate grader agent in its own independent context window** scores the working agent's output against the rubric and pinpoints what needs to change. Anthropic's internal benchmarks: **+10pp success on hardest tasks**, +8.4% on `.docx`, +10.1% on `.pptx`. The grader's isolated context is presented as the architectural reason it outperforms self-critique.
- **Dreaming → research preview** ([VentureBeat](https://venturebeat.com/technology/anthropic-introduces-dreaming-a-system-that-lets-ai-agents-learn-from-their-own-mistakes), [The New Stack](https://thenewstack.io/anthropic-managed-agents-dreaming-outcomes/), [DEV Community deep-dive](https://dev.to/evan-dong/anthropics-agents-now-self-improve-between-sessions-heres-how-dreaming-works-48l8)) — a **scheduled post-session process** reviews past sessions + memory, extracts recurring mistakes / converged workflows / shared preferences, and writes them as plain-text **playbooks** future sessions reference. Crucially: model weights are not changed; the artifact is human-auditable text.
- **Memory on Managed Agents → public beta** ([Releasebot Anthropic May 2026](https://releasebot.io/updates/anthropic)).
- **10 Finance Agent Templates** ([Fortune](https://fortune.com/2026/05/05/anthropic-wall-street-financial-services-agents-jamie-dimon/), [letsdatascience](https://letsdatascience.com/news/anthropic-launches-ten-finance-agent-templates-for-claude-6516f048)) — pitchbook, KYC screening, month-end close. Ships as plugin in Claude Cowork + Claude Code, and as a Managed-Agents cookbook.
- **Rate-limit doubling for Pro/Max** + 5-hour Code limit doubled; up to **17×** API rate limits for some tiers ([simonwillison live blog](https://simonwillison.net/2026/May/6/code-w-claude-2026/), [blakecrosley recap](https://blakecrosley.com/blog/code-with-claude-sf-2026-recap)).
