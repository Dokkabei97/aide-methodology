## How to Contribute a Translation

Translations follow the [Agent-First contribution model](../CONTRIBUTING.md):

1. **Open an Issue** indicating the target language.
2. **Use an AI agent** to perform the translation. Provide the agent with both the English source and any existing translations for reference.
3. **Submit a PR** with the translated file named `README-{LANG_CODE}.md` (e.g., `README-JA.md` for Japanese).
4. **Include agent usage information** in the PR (which agent, which model).
5. A native speaker should review the translation for accuracy and naturalness.

## Quality Guidelines

- **Technical terms** should remain in English where no widely-accepted translation exists, with a brief explanation in the target language on first use.
- **Consistency** — Use the same translated term for the same concept throughout the document.
- **Tone** — Maintain the professional but accessible tone of the original.
- **Completeness** — Translate the full document; do not omit sections.
- **Cultural context** — Where examples or references are culture-specific, adapt them appropriately while preserving the technical meaning.
- **Agent disclosure** — The PR must state which agent and model performed the translation.
