# AIDE (Agent-Informed Development Engineering) -- A Software Development Methodology for the Agentic Era v1.0

AIDE is a practical methodology for designing, building, and operating software systems with AI agents. It focuses on practical decomposition, interface contracts, and operational feedback loops across architecture, execution, and governance.

This index maps the original methodology into organized parts so each section can be read independently while preserving the original wording and ordering.
