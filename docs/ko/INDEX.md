# AIDE (Agent-Informed Development Engineering) -- 에이전트 시대의 소프트웨어 개발론 v1.0

AIDE는 AI 에이전트 기반 소프트웨어 개발 환경에서 아키텍처, 실행, 운영을 통합적으로 다루기 위한 실무형 방법론입니다. 실행 가능한 규칙과 조직적 합의를 통해 설계·개발·운영 전반의 일관성을 높이는 것을 목표로 합니다.

이 문서는 원본 방법론의 순서를 그대로 유지하면서도 파트 단위로 분리해 조회하기 쉽게 구성했습니다.

- [06-ADOPTION-GUIDE](./06-ADOPTION-GUIDE.md): 조직 도입 방법과 운영 가이드.
