# AIDE Example Projects

This directory will contain example projects that demonstrate AIDE principles in real codebases.

## Purpose

Examples serve as practical references for teams adopting the AIDE methodology. Each example should demonstrate one or more of the 10 Core Principles in a working codebase.

## Planned Examples

*No examples have been added yet.* We welcome contributions!

## Contributing an Example

Examples follow the [Agent-First contribution model](../CONTRIBUTING.md):

1. Open an Issue describing the example you want to create (language, framework, which principles it demonstrates).
2. Use an AI agent to implement the example project.
3. Submit a PR with agent usage information.
4. Maintainers and the community will review for alignment with AIDE principles.

### Requirements for Examples

- Must demonstrate at least one AIDE Core Principle clearly.
- Must include a README explaining which principles are demonstrated and how.
- Must be self-contained and runnable.
- Must follow the Agent-First contribution model (agent implements, human validates).
